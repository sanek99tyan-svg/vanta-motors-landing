# Vanta Motors landing page

A responsive, dependency-free dealership landing page built with plain HTML, CSS and JavaScript.

## Open locally

Double-click `index.html` or open it with the Live Server extension in VS Code.

## Main files

- `index.html` — page structure and English copy
- `style.css` — complete design, responsive breakpoints and animation
- `script.js` — mobile navigation, filters, counters, reveal effects and pointer interactions
- `assets/images/` — optimized automotive images

## Quick customization

Search for `VANTA MOTORS` in `index.html` to change the brand. Contact information is inside the `#contact` section. The main colors are CSS variables at the top of `style.css`.

All vehicle names and dealership details in this demo are fictional.
